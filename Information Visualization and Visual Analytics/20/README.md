# 序号20：说明文档 (D3.js)

本项目基于 D3.js 实现了一个分组径向条形图（Radial Bar Chart）。主要功能包括：多层级圆环绘制、SVG 图案纹理填充、极坐标下的复杂文字排版以及基于包围盒（BBox）的自适应布局算法。

## 1. 项目运行指南

### 如何启动
1.  确保本地环境支持运行 HTML/JS 文件（建议使用 VS Code 的 Live Server 插件或直接在浏览器打开）。
2.  打开项目根目录下的 `index.html` 文件即可看到渲染结果。

### 切换数据源
项目支持通过修改配置文件来渲染不同的数据集，无需修改核心绘图逻辑。

## 3. 核心功能与实现逻辑

### 3.1 视觉工程：高斯模糊与发光滤镜
为了提升图表的科技感与视觉层次，采用了 SVG 滤镜与渐变填充相结合的渲染策略。

* **光晕滤镜 (Glow Filter)**：定义 `<filter id="glow-blur">`，使用 `feGaussianBlur` 原语生成模糊效果。将其应用于扇形描边层（Stroke Layer）和图例光圈，创造出霓虹灯般的发光质感。
* **径向渐变填充 (Radial Gradient)**：为每个扇形生成独立的径向渐变。中心设置透明度较高的深色，边缘设置高亮主色，模拟“能量从圆心向外辐射”的视觉效果，增强了数据的指向性。

### 3.2 智能排序与旋转布局
图表并非随机排列，而是遵循严格的视觉权重逻辑，确保最重要的信息第一时间进入视野。

* **多级排序逻辑**：
    1.  **按组聚类 (Group Max)**：首先计算每个分组内的最大值，将拥有最大数值的**组**排在最前。
    2.  **组内降序 (Value Desc)**：在同一组内，数值大的条目排在前面。
    3.  **名称排序 (Category)**：数值相同时按名称排序，保证确定性。
* **视觉锚定 (Top-Left Alignment)**：
    * 计算排序后第一条数据（即最大值）的当前角度。
    * 计算目标角度（指向画布左上角，约 135° 方向）。
    * 应用全局 `rotationOffset`，强制最大扇形位于左上角。这是符合人眼扫描习惯（F型扫描）的视觉热点区域。

### 3.3 X轴标签排版 (Category Labels - 外周布局)
位于扇形末端的分类名称，采用了自适应的左右分区布局策略。

* **左右半区判断**：
    * 根据扇形中心角度 $\theta$ 判断：
    * **右半区 ($0 < \theta < \pi$)**：文字**左对齐** (`text-anchor: start`)，旋转角度 $+90^\circ$（从圆心向外辐射）。
    * **左半区 ($\pi < \theta < 2\pi$)**：文字**右对齐** (`text-anchor: end`)，旋转角度 $-90^\circ$（从外向圆心辐射）。
    * **效果**：确保文字始终垂直于半径线，且阅读方向统一朝上，避免文字倒挂。
* **自动字号缩放公式**：
    为了防止长标签在有限的扇形带宽内重叠，采用了动态字号计算：
    $$FontSize = \frac{ArcWidth}{\sqrt{TextLength} \times Ratio} \times 0.6$$
    * 其中 `ArcWidth` 为物理弧宽，`Ratio` 为中英文宽度系数（中文 1.0，英文 0.6）。
    * 使用平方根 (`sqrt`) 进行非线性缩放，防止短文本字号过大，长文本字号过小，最终结果限制在 `minFontSize` (9px) 至 `maxFontSize` (30px) 之间。

### 3.4 Y轴标签排版 (Value Labels - 环绕圆弧)
位于扇形内部或边缘的数值标签，使用 `textPath` 实现沿弧线弯曲排列。

* **上下半区反转逻辑**：
    * **上半圆**：定义路径方向为 **顺时针** (Start $\to$ End)。文字自然正向显示。
    * **下半圆**：定义路径方向为 **逆时针** (End $\to$ Start)。如果不处理，下半圆的文字会倒立。通过反转路径方向，强制文字“脚朝圆心”，保持直立阅读体验。
* **边缘检测**：当扇形半径过短时，算法自动将数值标签推至扇形外部，并反转文字颜色以保证对比度。

### 3.5 分组可视化策略 (Group Visualization)
针对数据分组，设计了两种差异化的表现形式，以平衡视觉密度。

* **多条目组 (Size > 1) - 扇环模式**：
    * 对于包含多个条目的组，在扇形外围绘制一条连续的**圆弧带 (Group Arc)**。
    * 圆弧覆盖该组所有扇形的角度范围，并应用磨砂玻璃质感的半透明填充与高亮描边。
    * 组名文字沿圆弧排列（同样应用上下半区反转逻辑）。
* **单条目组 (Size = 1) - 图标模式**：
    * 对于“单飞”的数据（该组只有一个条目），绘制外围圆环会显得冗余。
    * **处理方式**：不画圆弧，而是直接在数值标签的顺时针起始侧（Start Angle）绘制一个**圆形图标**（或填充了图片的 Pattern 圆点）。
    * 这种处理既节省了空间，又突出了单条数据的特性，避免了视觉上的割裂感。

### 3.6 标题与副标题的智能排版 (Smart Title Layout)
为了解决长标题在固定 SVG 区域内溢出或覆盖图表的问题，系统摒弃了传统的“固定字号+自动换行”模式，转而采用了一套**基于区域约束的递归自适应算法** (`fitTextByWordCount`)。

* **基于单词数的逻辑换行 (Word-based Wrapping)**：
    * 根据预设的密度参数（如 `maxWordsPerLine = 5`），将长文本强制切分为每行包含固定数量单词的文本块。这确保了排版的整齐度，避免了单词在行尾被截断的破碎感。
* **递归自适应缩放 (Recursive Auto-Fitting)**：
    * 采用“**试错法 (Trial & Error)**”渲染机制。算法首先尝试以设定的最大字号（如 60px）渲染文本。
    * 通过 `getBBox()` 实时测量渲染后的文本块实际宽高。
    * **边界检测**：如果文本块的高度超出 `titleAreaH` 或宽度超出 `titleAreaW`，算法自动将字号减小 2px 并**重绘**，循环此过程直至文本完美容纳于限定区域内或触及最小字号底限（10px）。
