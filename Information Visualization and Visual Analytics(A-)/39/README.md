# 序号39：说明文档 (D3.js Implementation)

本项目是一个基于 D3.js 的动态可视化图表系统，旨在展示不同类别（如国家、媒介类型）在两个时间点（Base Year vs Target Year）之间的数值变化。项目具备高度的泛化能力和容错机制，能够自动适配各种极端数据情况，并实现了复杂的自动化布局算法。

## 1. 项目运行指南

### 如何启动
1.  确保本地环境支持运行 HTML/JS 文件（建议使用 VS Code 的 Live Server 插件或直接在浏览器打开）。
2.  打开项目根目录下的 `index.html` 文件即可看到渲染结果。

### 切换数据源
项目支持通过修改配置文件来渲染不同的数据集，无需修改核心绘图逻辑。
* 打开 `sample_39.js` 文件。
* 定位到 **第 15 行** 代码：
    ```javascript
    d3.json("example_2_all_up.json").then(config => { ...
    ```
* 修改 `d3.json()` 中的文件名字符串，即可切换读取不同的 `.json` 数据文件。

## 3. 系统功能与核心技术细节

本项目不仅仅是一个静态图表，更是一个具备高度自适应能力的绘图系统。核心设计理念是**“数据驱动布局”**与**“视觉工程化”**。

### 3.1 强大的容错处理与数据校验 (Robustness)
为了防止脏数据导致图表渲染错误，在绘图前植入了严格的断言机制（Assertions）：
* **全局年份校验**：系统自动扫描所有数据，确保全局严格只有两个对比年份（Base Year vs Target Year）。如果出现第三个年份，立即报错。
* **分组完整性校验**：针对每个类别（X轴），检查是否严格包含 2 条记录。缺失或多余数据均会触发断言失败。
* **唯一性校验**：自动检测同一类别下是否存在重复年份（例如两条数据都是 2024）。
* **实现方式**：利用 `d3.group` 和 `d3.rollup` 进行数据预处理，任何不符合预期的数据结构都会抛出显式错误，保证渲染出的图表绝对准确。

### 3.2 智能布局策略 (Auto-Layout)
系统不再硬编码标题和图例的位置，而是根据数据的“涨跌趋势”动态决定：
* **趋势检测与标题避让**：算法会分析前 30% 数据的涨跌情况。
    * **全涨/主涨模式**：标题自动**沉底**（移至下方），图例置于上方。
    * **全跌/主跌模式**：标题自动**置顶**，图例置于下方。
* **碰撞检测 (Collision Detection)**：在绘制标题时，算法会扫描每一根柱子的 X 坐标和半径，动态计算标题的可用宽度，确保文字永远不会覆盖在数据柱体上。
* **图例锚定 (Legend Anchoring)**：图例的位置不再是绝对坐标，而是基于右侧标尺（Ruler）的相对坐标计算，确保无论图表宽窄，图例始终紧贴标尺左侧，不会重叠。

### 3.3 自适应坐标轴与网格 (Adaptive Axis)
* **基准线锁定**：强制 $y=0$ 的基准线（No Change Line）始终保持在画布高度的 **35% ~ 65%** 之间。系统会自动撑大上方或下方的空间，防止全涨或全跌时基准线贴边，影响阅读。
* **智能网格 (Smart Grid)**：网格线的绘制范围是动态计算的（Visual Boundaries）。虽然画布被逻辑撑大了，但**只有在有真实数据覆盖的区域**才会绘制网格线，保持画面的整洁。
* **视觉锚定**：0 值基准线使用**实线、加粗、纯白**样式，而其他刻度线使用**虚线、半透明**样式，建立清晰的视觉层级。

### 3.4 视觉工程与精细渲染 (Advanced Rendering)
* **“伪透明”实心色计算**：
    * 为了防止底部的连接柱（Bar）透过半透明的圆心显示出来（造成视觉干扰），系统使用 `d3.interpolateRgb` 计算了一个**看起来像半透明但实际是不透明**的实心颜色。这是一种高级的视觉处理技巧。
* **几何切线连接 (Pill Geometry)**：
    * 连接两个圆的路径并非简单的矩形，而是基于切线计算生成的**梯形圆头路径**。即使两个圆大小差异巨大，连接处也能平滑过渡。
* **定向动态渐变**：
    * 渐变的方向根据数据的涨跌动态生成。亮色始终位于基准端，暗色位于末端，创造出一种数据的“运动拖尾感”。
* **智能颜色反转**：
    * 利用感知亮度公式（Perceived Brightness）计算背景圆的颜色。如果是浅色背景（如黄色），内部文字自动变为**黑色**；如果是深色背景，文字保持**白色**，确保最佳对比度。

### 3.5 智能排版 (Smart Typography)
* **X轴标签自适应**：
    * **布局切换**：当国家/类别名称长度超过 5 个字符时，自动切换为**纵向布局**（国旗在上，文字在下）；短名称保持**横向布局**。
    * **字体缩放**：自动计算文字宽度与圆柱宽度的比例。如果文字过长，会自动缩小字号（Font Scaling），防止遮挡相邻元素。
* **数值标签防重叠**：
    * 当变化量极小（如 +3pp）导致柱体空间不足时，算法会自动将数值标签移至**圆柱体外部**，并自动调整颜色。
* **全局自动缩放**：
    * 在渲染前预计算总宽度。如果数据条目过多（如从 7 个增加到 12 个），系统会自动计算缩放系数（Scale Factor），按比例缩小圆的半径和间距，确保所有内容完美适配屏幕宽度，不会溢出。
